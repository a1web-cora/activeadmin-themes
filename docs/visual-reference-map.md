## Largest Source-Based Mismatch Candidates

These are priorities inferred from source, **not fresh browser findings**. Confirm actual computed styles and before/after screenshots on each final PR head.

1. **Canvas and section hierarchy.** AA3's body is white, with gray section backgrounds and compact title bands. Current V3 uses a gray page canvas and white panels. Pending panel titles use 12px vertical padding and 16px type; AA3 section headers use 5px/3px padding, 18px line-height and body-sized bold type. Investigate this inversion and oversized section headings first.
2. **Typography and index chrome—not indiscriminate shrinking.** AA3's final body rule is 72% (about 11.52px with a 16px default), versus current 14px. Historical table headers use the compact section-header geometry; ours apply 8px vertical padding to both headings and cells. But AA3 body cells use 10px top/8px bottom, versus our 8px/8px: do not incorrectly claim all historical padding was smaller. Keep readable text; tune header/tool rhythm independently.
3. **Actions and current states.** AA3 has dark neutral primary buttons, light secondary buttons and a dark current page; pending forms/filters/login use blue primary fills, while current pagination/scopes use pale blue plus underline. Review neutral button tokens and compact segmented/tool treatment without removing non-color state cues or usable targets. Historical pagination's 2px/5px padding is not a touch-target requirement.
4. **Login identity.** AA3 uses a 500px wrapper with 70px top margin and a compact dark heading; pending login uses a 28rem maximum card with 24px heading padding and 24px type. Restore the restrained heading hierarchy, not fixed positioning or floated auxiliary links.
5. **Attributes, filters and status detail.** Historical attribute labels are small uppercase, gray and differentiated from values; pending styling uses ordinary text and gray header cells. Historical filters have compact sidebar labels and grouped controls; pending titles/spacing are larger. Historical status tags are tiny uppercase gray/blue blocks; pending tags are rounded neutral/pastel treatments with green “yes.” Review visual weight, but retain visible words, adequate contrast and neutral handling of arbitrary domain statuses.
6. **Navigation geometry is an intentional exception.** AA3's horizontal header differs fundamentally from AA4's drawer. Preserve the drawer and native hooks; refine title/breadcrumb/menu visual hierarchy rather than rebuilding AA3 navigation. Current text/link/selected colors already match AA3 values `#323537`, `#38678b`, `#d9e4ec`; the 30px desktop gutter also matches. Do not replace correct shared values merely to create a diff.
